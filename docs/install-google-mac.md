# Mac版Google日本語入力への導入

この手順は2026-10-21版の小規模試用向けです。辞書データの変換エンジン試験、TextEditの2文、辞書ツールからのTXT取り込み（macOS 26.6.2・Google日本語入力3.34.6260.1）は確認済みです。確認した範囲は[検証結果](verification.md)にあります。対象のGoogle日本語入力を使っていることを確かめて進めてください。WindowsやApple標準の日本語入力へ、そのまま使えるという意味ではありません。

## 取り込み前

業務のレポート入力を止め、[元に戻す手順](restore.md)を先に開きます。辞書ツールの左側にある既存の辞書名を控えてください。

既存の個人辞書は、それぞれを選択して「管理」内のエクスポート機能でTXTへ保存します。エクスポート対象の辞書を取り違えず、保存先とファイルを開けることを確認してください。保存したTXTは個人情報を含むことがあるので、GitHubへ投稿しません。学習履歴の削除は不要です。

## ファイルの準備

取り込むのは `tulipkite-medical-dictionary-2026-10-21.txt` の1ファイルだけです。[Releaseのページ](https://github.com/tulipkite/medical-dictionary/releases)の「Assets」からダウンロードします（リポジトリの `dictionary/google/tulipkite-medical-dictionary.txt` と同じ内容で、ファイル名に版の日付を付けたものです）。`source/`、`provenance/`、検証JSON、HTMLページは取り込みません。UTF-8で日本語の読み・表記・品詞がタブ区切りになっていることを確認します。

ターミナルを使える場合は、保存したフォルダで次を実行できます。

```sh
shasum -a 256 tulipkite-medical-dictionary-2026-10-21.txt
```

結果は `7cbce0405e5b1c244afd9db6b1ed05873470c341f5ef0dd554d810c62c43148d` です。SHA256は内容の照合用で、配布者の署名ではありません。

## 専用辞書へ取り込む

1. Mac上部のGoogle日本語入力メニューから「辞書ツール」を開きます。
2. 「管理」から「新規辞書にインポート」を選びます。「選択した辞書にインポート」は使いません。
3. `tulipkite-medical-dictionary-2026-10-21.txt` を選び、辞書名を `Tulipkite Medical Dictionary 2026-10-21` とします。既に同名がある場合は中止して登録内容を確認します。
4. 取り込みの完了表示と登録数を確認します。期待する登録数は1153です。読み飛ばしや品詞エラーがあれば完了と扱いません。
5. 新しく作った専用辞書を選び、エクスポート機能でTXTへ保存します。画面上の件数だけでなく、取り込まれた内容も確認します。

メニュー名は確認した版（Google日本語入力3.34.6260.1）のものです。ほかの版では異なる場合があります。Googleのオープンソース版Mozcには、新規辞書への取り込み、選択中の辞書への追加、選択中の辞書の出力が別々に実装されています。[実装](https://github.com/google/mozc/blob/master/src/gui/dictionary_tool/dictionary_tool.cc)

Pythonを使える場合、エクスポートしたファイルを次のように照合できます。ファイル名は自分の保存先に置き換えてください。この検査はファイルを読むだけで、IMEには接続しません。

```sh
python3 scripts/check.py --export '/path/to/exported-dictionary.txt'
```

登録数と、読み・表記・品詞の組み合わせが一致するかを調べます。行順やUTF-8のBOM・改行コードの差は無視します。コメント列は照合から除き、コメントを持つ行の数を表示します。バックアップ自体を書き換えることはありません。

## 実際に変換する

TextEdit等の空の文書でGoogle日本語入力のひらがなモードを選び、次の読みをローマ字で入力してスペースを1回押します。正解文のコピー・貼り付けを動作確認にしないでください。

| 読み | 確認する表記 |
| --- | --- |
| かせいりゅうをみとめます | 仮性瘤を認めます |
| たぼうせいののうほうせいびょうへん | 多房性の嚢胞性病変 |

文節の拡張や候補選択が必要だった場合は、その環境では一発変換できなかった結果として扱います。通常の導入では学習設定を変更しません。学習なしでの確認方法は[検証記録](verification.md)に記載しています。

遠隔接続では、ローカルの成功と接続先での成功を分けます。Mac版Windows AppでローカルIMEを使うにはUnicodeモードが必要と説明されていますが、実際の接続先で必ず確認してください。[Microsoftの説明](https://learn.microsoft.com/en-us/windows-app/input-keyboard-mouse-touch-pen#input-method-editor)

## 失敗した場合

エラーや強い負荷、無反応が起きたら、取り込みを繰り返さず辞書ツールを通常終了します。通常終了できない場合は辞書ツールだけの終了を検討し、変換エンジンやDBファイルを直接操作しません。再度開いて専用辞書の有無と内容を確認し、[復元手順](restore.md)に進みます。バックアップと他の個人辞書は保持してください。
