# 無償公開と今後の方針

Tulipkiteの無料オープンソースプロジェクトとして、放射線科・IVRの日本語入力を改善します。購入意思や売上を初期の成功条件にせず、他の医師が導入して使え、誤変換や困った点を報告できることを目標にします。

## 最初の配布

2026-10-21版の辞書、導入・更新・復元手順、出典・ライセンス、再生成ソース、確認済みの結果と未検証の範囲を公開用に揃えます。利用者には取り込み用TXTを1つだけ示し、原典全体や端末内バックアップを取り込ませる構成にしません。

試用版（Pre-release）であることを示した小規模試用から始めます。辞書ツールでの復元、別Mac、実際の遠隔入力は、確認できた環境から記録を加えます。未確認の環境を対応済みと表示しません。

## 用例と利用環境を増やす

架空の用例で、読み・期待表記・実際の表記・環境・学習条件を集めます。修正した用例は回帰用にし、独立した未知文の評価とは分けます。否定、左右、数値、時制と一般語への影響を確認します。

## ほかのIMEへの対応

Android版Gboard用の取り込みZIPは、実機で確認できていないため初回の配布に含めていません。Gboard、Windows版Google日本語入力、Microsoft IME、Apple標準の日本語入力は、実機で取り込みと変換を確認できたものから追加します。

## 必要な管理機能を育てる

辞書TXTと手順書だけでは困る箇所を確認してから、導入前の保存、出力後の照合、更新と以前の版への復元、個人追加語の分離、端末間の移行を支援する無料アプリを検討します。管理アプリは現時点では未実装です。

クラウド同期、課金、広告、入力文章の収集を最初の管理アプリの前提にしません。Mac限定で需要に合わない場合はWindows等を優先する判断も行います。保守は可能な範囲で続け、個別の回答期限や無期限の更新提供を約束する形にはしません。
