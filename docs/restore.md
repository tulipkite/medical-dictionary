# 元の状態へ戻す

復元する対象は、今回追加した医療辞書だけです。Google日本語入力全体の初期化、学習履歴のクリア、DBファイルの上書きは行いません。作業中のレポート入力を止めて進めます。

## 新規導入を取り消す

1. 辞書ツールを開き、今回作成した `Tulipkite Medical Dictionary 2026-10-21` を選択します。
2. 自分で追加・変更した語があれば、まずその辞書をTXTへエクスポートして保存します。分からない場合も保存します。
3. 選択中の辞書名を再確認して、その専用辞書だけを削除します。辞書内の自分の追加語も消える操作なので、保存後に実行します。
4. 他の辞書が残っていることを確認し、通常の文書で入力を確かめます。

新規の専用辞書だけに取り込んでいた場合、以前の個人辞書をインポートし直す必要はありません。これにより重複登録を避けます。

## 間違えて個人辞書へ混ぜた場合

専用辞書の削除手順を、その個人辞書に対して実行しないでください。最初に現在の辞書をエクスポートします。導入前のバックアップがある場合でも、導入後に加えた個人語がないかを確認し、保存してから戻す範囲を決めます。

バックアップがない場合、読みや表記が同じ登録から元の個人語と追加分を完全に区別できないことがあります。全件削除や推測による一括除去を避け、個別の確認が必要です。この配布物には個人辞書を自動修復するツールは含めていません。

## 学習設定について

導入自体は学習設定を変更しません。任意の検証で一時変更した場合だけ、控えておいた元の設定へ戻してください。学習履歴を消しても辞書の復元にはならず、辞書TXTから学習履歴を復元することもできません。
