# 編集用ソース

現在の辞書を変更する際の原本は、次の3つのUTF-8・LF・タブ区切りファイルです。取り込み先はIMEではなく再生成スクリプトです。

| ファイル | 内容 |
| --- | --- |
| core.tsv | 基本1000語。全て名詞 |
| priority.tsv | 基本語の優先指定37登録 |
| context.tsv | 語句や活用形など、文中変換用116登録 |

各行は「読み・表記・品詞」の3列で、ヘッダーはありません。同じ読み・表記でも品詞が異なる意図的な登録は保持します。完全に同じ3列の重複は認めません。文中変換用にも短縮よみの品詞を使う行があるため、「優先指定37登録」と「短縮よみの総数」は同じではありません。

```sh
python3 scripts/build.py --output build
```

生成された `build/tulipkite-medical-dictionary.txt` は、現在の配布TXTとバイト単位で一致します。内容を変更した場合は、生成物・版情報・検証対象を併せて更新してください。原典全体を再取り込みする必要はありません。

基本語の選定履歴は[core-selection.json](../provenance/core-selection.json)、出典は[NOTICE.md](../NOTICE.md)にあります。これらは現行版の編集用ソースと来歴を提供するもので、原典の全4万語を収録した配布物ではありません。
